# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give HyperShell a coherent polished visual layer — shared design tokens + UI primitives, then sweep sidebar/hosts, tabs/status bar, dialogs, and settings/welcome to use them.

**Architecture:** Extend the existing Tailwind v4 semantic-token system in `apps/ui/src/index.css` with elevation/motion/focus tokens; add thin wrapper primitives in `apps/ui/src/components/ui/`; refactor surfaces in dependency order. All color flows through existing semantic vars so every theme inherits changes.

**Tech Stack:** React 18, Tailwind CSS v4 (CSS-first `@theme`), framer-motion (already installed), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-03-ui-polish-design.md`

## Global Constraints

- **No new dependencies.** Primitives are plain Tailwind wrappers; framer-motion is already installed.
- **No hardcoded palette colors.** Never use Tailwind palette classes (`bg-green-400`, `bg-red-600`, `text-cyan-400`); only semantic tokens (`bg-success`, `bg-danger`, `text-accent`, `bg-base-700`, …). Existing hardcoded colors you touch are bugs — fix them.
- **Behavior must not change** except the explicitly planned UX moves (export/import relocation, tag-chips-behind-filter, collapsible groups, hover SFTP button, empty-state actions). Focus traps, drag-and-drop, keyboard shortcuts, IPC calls all stay intact.
- **TypeScript strict**; keep existing ESLint clean (`pnpm lint`).
- **Motion durations** come from `--motion-fast` (120ms) / `--motion-base` (180ms) / `--motion-slow` (260ms). In Tailwind classes use the v4 CSS-var shorthand, e.g. `duration-(--motion-fast)`. In framer-motion use the constants from `apps/ui/src/lib/motion.ts` (Task 12).
- **Verification cadence:** every task ends with `pnpm --filter @hypershell/ui test` and `pnpm lint` green, then a commit. Playwright browser E2E (`pnpm --filter @hypershell/ui test:e2e`) runs at the end of each phase (Tasks 9, 11, 16, 19) and in Task 20.
- Themes to keep working: default dark (`:root`), `default-light`, `mocha`, `nord` (all in `apps/ui/src/index.css`).

```ts
export type ButtonVariant = "primary" | "ghost" | "outline" | "danger";
export type ButtonSize = "sm" | "md";
export type IconButtonVariant = "ghost" | "accent";

const BUTTON_BASE =
  "inline-flex items-center justify-center gap-1.5 rounded-lg font-medium cursor-pointer select-none transition-colors duration-(--motion-fast) ease-standard focus-ring disabled:cursor-not-allowed disabled:opacity-50";

const BUTTON_SIZES: Record<ButtonSize, string> = {
  sm: "px-3 py-1.5 text-xs",
  md: "px-3.5 py-2 text-sm",
};

const BUTTON_VARIANTS: Record<ButtonVariant, string> = {
  primary: "border border-accent/40 bg-accent/15 text-accent hover:bg-accent/25",
  outline:
    "border border-border bg-base-750/70 text-text-secondary hover:border-accent/35 hover:text-text-primary",
  ghost: "text-text-secondary hover:text-text-primary hover:bg-base-700/60",
  danger: "border border-danger/40 bg-danger/15 text-danger hover:bg-danger/25",
};

const ICON_BUTTON_BASE =
  "inline-flex items-center justify-center rounded-md p-1 cursor-pointer transition-colors duration-(--motion-fast) ease-standard focus-ring disabled:cursor-not-allowed disabled:opacity-50";

const ICON_BUTTON_VARIANTS: Record<IconButtonVariant, string> = {
  ghost: "text-text-muted hover:text-text-primary hover:bg-base-700/60",
  accent: "text-text-muted hover:text-accent/80 hover:bg-accent/[0.06]",
};

export function buttonClassName(variant: ButtonVariant, size: ButtonSize): string {
  return `${BUTTON_BASE} ${BUTTON_SIZES[size]} ${BUTTON_VARIANTS[variant]}`;
}

export function iconButtonClassName(variant: IconButtonVariant): string {
  return `${ICON_BUTTON_BASE} ${ICON_BUTTON_VARIANTS[variant]}`;
}
```

`apps/ui/src/features/hosts/useHostExport.ts` — move the logic currently in `SidebarHostList.handleExportHosts` (lines 373–399) verbatim, parameterized by format:

```ts
import { useCallback } from "react";
import { toast } from "sonner";

export type HostExportFormat = "json" | "csv" | "ssh-config";

const EXPORT_OPTIONS: Record<
  HostExportFormat,
  { extension: string; filterName: string }
> = {
  json: { extension: "json", filterName: "JSON" },
  csv: { extension: "csv", filterName: "CSV" },
  "ssh-config": { extension: "conf", filterName: "SSH Config" },
};

export function useHostExport() {
  const exportHosts = useCallback(async (format: HostExportFormat) => {
    const option = EXPORT_OPTIONS[format];

    if (!window.hypershell?.fsShowSaveDialog || !window.hypershell?.exportHosts) {
      toast.error("Host export is unavailable in this environment.");
      return;
    }

    const filePath = await window.hypershell.fsShowSaveDialog({
      defaultPath: `hosts.${option.extension}`,
      filters: [{ name: option.filterName, extensions: [option.extension] }],
    });
    if (!filePath) {
      return;
    }

    try {
      const result = await window.hypershell.exportHosts({ format, filePath });
      toast.success(
        `Exported ${result.exported} host${result.exported === 1 ? "" : "s"} to ${filePath}`
      );
    } catch (error) {
      toast.error(
        `Export failed: ${error instanceof Error ? error.message : String(error)}`
      );
    }
  }, []);

  return { exportHosts };
}
```

```ts
const STORAGE_KEY = "hypershell.sidebar.collapsedGroups";

export function loadCollapsedGroups(): Set<string> {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    if (!raw) return new Set();
    const parsed: unknown = JSON.parse(raw);
    if (!Array.isArray(parsed)) return new Set();
    return new Set(parsed.filter((v): v is string => typeof v === "string"));
  } catch {
    return new Set();
  }
}

export function saveCollapsedGroups(groups: Set<string>): void {
  try {
    localStorage.setItem(STORAGE_KEY, JSON.stringify([...groups]));
  } catch {
    // storage unavailable — collapse state just won't persist
  }
}
```
